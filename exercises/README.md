# Exercises

Use these exercises to turn each lesson into working code.

## Beginner track

### Exercise 1 — Personal profile

Create variables for a person's name, age, city, and whether they are a student. Log a short profile message.

### Exercise 2 — Number checker

Write a function that receives a number and reports whether it is positive, negative, or zero.

### Exercise 3 — Technology list

Create an array of technologies. Add an item, remove an item, and create a second array containing only items with more than three characters.

## Rules

- Attempt each exercise before looking for a solution.
- Keep your solution in a separate file or folder.
- Prefer readable code over clever code.
- Test edge cases such as `0`, an empty array, and unexpected input.
