# Contributing

Thanks for helping improve this JavaScript learning repository.

## Before contributing

1. Check existing issues and pull requests.
2. Keep examples beginner-friendly and focused.
3. Explain why a change improves the learning material.

## Pull requests

- Use a clear title.
- Keep each pull request focused on one improvement.
- Test code examples before submitting.
- Update documentation when an example changes.

## Good contributions

- Correcting an inaccurate explanation.
- Adding a useful JavaScript example.
- Improving exercise instructions.
- Fixing broken or unclear code.
